# Documentation

Bienvenue dans la documentation de Gaslands Manager. Elle explique comment
utiliser l'application : les équipes, la construction de véhicules, les
campagnes, le Programme Télé, l'Atelier et les Séquelles.

Cette documentation suppose que vous connaissez déjà les **règles du jeu de
plateau Gaslands** (activations, dés d'attaque, gabarits de mouvement...).
Elle ne les explique pas. Elle explique en revanche en détail les mécaniques
propres au **mode campagne** de l'application, qui n'existent pas dans le
livre de règles : les Chocs, les Séquelles, la revente d'équipement, les
Points de Résistance, et comment elles s'articulent entre elles à l'écran.

Chaque page de l'application propose un lien **❓ Aide sur cet écran** qui
vous amène directement au chapitre concerné. Vous pouvez aussi parcourir les
chapitres dans l'ordre ci-dessous — chacun renvoie vers les suivants quand
c'est utile, pour suivre le fil d'une partie de bout en bout : créer une
équipe, l'équiper, l'engager dans une campagne, jouer une partie, régler
l'Atelier, encaisser les Séquelles.
